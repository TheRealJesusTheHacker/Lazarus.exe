WHAT THIS IS
------------
Lazarus is Sentinel Safeguard's backup, restore, and file
recovery tool for Windows. It brings back files that were
deleted, folders that were overwritten, and data trapped on
drives that are failing or locked - and it backs everything up
before disaster, versioned by date, so the next loss is a
restore instead of a funeral. Every recovery starts with
honest odds, stated before Lazarus makes any promise.

This folder holds the portable edition: the exact same
Lazarus.exe as the regular edition - one file that contains
everything - with no installer involved.

HOW TO RUN IT
-------------
Double-click Lazarus.exe, right here in this folder. It runs
from a USB stick, from your downloads folder, from anywhere.
Nothing needs to be set up first.

NO INSTALL NEEDED
-----------------
The portable copy does not install itself. Running it does not
copy Lazarus into Program Files, does not add it to the Start
Menu, and does not change your computer's settings. If you
close it and delete this folder, Lazarus the program is gone.

WHAT LAZARUS WRITES, AND WHERE - THE HONEST FOOTPRINT
-----------------------------------------------------
"Portable" describes the program, not your data. Lazarus is a
backup and recovery tool, so when YOU ask it to do a job, it
writes the results of that job - that is the job. Plainly:

- Backup settings and run history live under your own user
  folder, in a folder named .lazarus, so Lazarus remembers
  which folders you back up and when they last ran.
- Snapshot stores, restored files, drive-rescue images, and
  report files are created only where you point Lazarus -
  the drive or folder you choose for each one. Lazarus never
  picks a place for your data on its own.
- A decryptor run works on copies inside a work area Lazarus
  prepares where you tell it to; your originals are hashed
  before and after and are never changed.

So: no fake "leaves no trace" promise. The program itself
installs nothing and changes no settings, and everything it
writes beyond its own small settings folder is a file you
asked it to make, in a place you chose.

THE INSTALL OFFER
-----------------
The shipped Lazarus.exe may OFFER to install itself on your
computer - copying itself into Program Files under
Sentinel Safeguard\Lazarus and adding one Start Menu shortcut,
so it is easy to find next time. That is all an install is:
one folder and one shortcut. No registry changes, no PATH
changes, no services. And an offer is all it ever is - the
portable copy never installs without you saying yes, and
running it from this folder keeps working exactly as before
whether you accept the offer or not. Removing an installed
copy is done from a portable copy like this one, and removes
that folder and that shortcut.

WINDOWS NOTES
-------------
Lazarus runs on Windows. Two of its jobs lean on Windows' own
tools, by design: opening a BitLocker volume uses Windows' own
unlock, with your own recovery key, and scheduled backups are
kept by Windows Task Scheduler. Those two jobs are Windows-only
because the tools they ask for help are Windows' own.

Your drives, your keys, your files. Lazarus never tries to
defeat encryption you don't hold the key to, and it never
promises a recovery it can't honestly deliver.
